# finalexam_trustingthechecker
Rubric::: judge ke liye likhi hui marking guide hai. Is mein likha hota hai ke har number ka kya matlab hai, aur har number ke saath ek asal misaal hoti hai. Jaise: "8 tab jab kaam sahi ho, lekin ek chhoti kami ho."
PASS ka matlab: is ek kaam ko checker ne theek kaha.
Kai baar ak kaam chalana isliye: ta ke pata chale ke agent aam taur par kitni baar theek karta hai, sirf is ek baar nahi.
Test: ek cheez ko ek baar dekhta hai. 2 + 2 = 4 jaisi cheez, jahan jawab kabhi nahi badalta.
Eval: wahi kaam kai baar chalata hai aur ginta hai kitni baar theek hua. Bus(Gad ki roz any ki dlti hoi timngs) jaisi cheez ke liye, jahan natija badalta rehta hai.
Ek PASS kaafi nahi: agent ka jawab kabhi alag aa sakta hai, isliye ek PASS sirf itna batata hai ke is baar PASS aaya.
Bar = kam se kam itna jitna hona chahiye, tab hi kaam ko "theek" maana jayega. Jaise imtihan mein pass marks.
